Key libraries explained

New libraries for this project
pip install requests beautifulsoup4 lxml soccerdata plotly geopandas
requests — sends HTTP requests to websites. This is how we fetch web pages to scrape data from Transfermarkt and other sources.

beautifulsoup4 + lxml — parses HTML from web pages and extracts the data we need. BeautifulSoup is the standard web scraping library in Python. lxml is the fast HTML parser it uses underneath.

soccerdata — a Python library that provides clean access to FBref, Sofascore, and other football data sources without needing to scrape manually.

plotly — creates interactive charts (hover, zoom, filter) unlike matplotlib which creates static images. Used for the migration flow maps and interactive visualisations.

geopandas — extends pandas to support geographic data. Lets us create choropleth maps of Africa showing player counts and success rates by country.

Web scraping explained

How web scraping works
import requests from bs4 import BeautifulSoup headers = {'User-Agent': 'Mozilla/5.0'} url = 'https://www.transfermarkt.com/...' response = requests.get(url, headers=headers) soup = BeautifulSoup(response.content, 'lxml') table = soup.find('table', {'class': 'items'})
How it works: requests.get() sends an HTTP request to the website — exactly like your browser does when you visit a page. The response contains the full HTML of the page.

Why headers? Websites can detect and block automated requests. Including a User-Agent header makes our request look like it came from a real browser rather than a script.

BeautifulSoup parses the HTML and gives us tools to find specific elements — tables, rows, cells — just like selecting elements in JavaScript. soup.find() locates the first matching element. soup.find_all() finds all matching elements.

Ethical scraping rules: Always add delays between requests (time.sleep), never overload a server, respect robots.txt, and only scrape publicly available data.

A database of African footballers currently playing in European leagues — their nationality, position, market value, age, and current club. This becomes the foundation for all subsequent analysis: migration patterns, value growth, success rates, and the ML model that identifies undervalued talent.
